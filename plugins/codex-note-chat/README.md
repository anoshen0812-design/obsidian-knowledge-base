# Codex Note Chat

在 Markdown 笔记标签页工具栏点击“向 Codex 询问当前笔记”按钮，打开可拖动、八方向缩放的问答浮窗。窗口位置和尺寸会自动记忆；回答区使用适合长文阅读的紧凑排版并独立滚动。

## 上下文

- 始终包含当前笔记。
- 自动解析当前笔记 YAML 中的 `source_pdf`；若没有该属性，则查找笔记中的第一个 PDF 出链。
- 可选加入当前笔记中的选中文本，编辑模式和阅读模式均可使用。浮窗打开后仍可回到笔记选择文字，再点击“捕获选区”；捕获内容会保留到本轮发送时。
- 可选加入当前笔记直接链接的 Markdown 笔记，最多 12 篇。

问答线程以知识库根目录为工作目录，并强制使用 Codex `read-only` 沙箱和 `never` 审批策略。

## 写入

问答不会自动修改笔记。点击“写入笔记”后，Obsidian 才会把尚未保存的问答写入当前笔记，格式如下；后续写入会复用同一个 `# 提问` 区域并延续序号。

```markdown
# 提问

## 1

Q：问题

A：回答

## 2

Q：下一个问题

A：下一个回答
```

## 人工复核

- 笔记包含 `## 人工复核` 任务清单时，可点击“开始复核”。Codex 会逐项读取来源 PDF、报告证据与问题，并给出通过或阻塞结论。
- 只有全部任务复核通过且笔记自复核后未发生变化，“完成审核”才会启用。
- 点击“完成审核”并确认后，插件会勾选该节中的待办项，并写入 `reviewed: true`、`reviewed_at`、`reviewed_with: codex-note-chat`。
- 完成审核不会自动写入对话正文；如需保留对话，仍由你另行点击“写入笔记”。

## 操作

- `Enter`：发送问题。
- `Shift + Enter`：换行。
- 回答期间点击“停止”：中断当前回答。
- 拖动标题栏：移动浮窗。
- 标题栏获得焦点后使用方向键：移动浮窗；按住 `Shift` 可加大移动步长。
- 拖动浮窗的任一边缘或四角：调整浮窗尺寸。
- 浮窗打开后在笔记里选择文字，再点击“捕获选区”：更新可选的选区上下文。

插件读取 `system/knowledge/config.json` 中的 `codex_path` 和 `proxy_url`，并复用本机 Codex 登录状态。
